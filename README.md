# ChessZone Online — шахматы с другом

Это **рабочий учебный проект** для VS Code: игра вдвоём в реальном времени, комнаты по ссылке, чат, правила шахмат, шах/мат/пат, превращение пешки, рокировка, сдача, реванш. Дизайн можно самостоятельно менять в `public/style.css`.

## Что установить

- Node.js LTS (https://nodejs.org/) и VS Code.
- В VS Code открыть **всю папку** `chesszone-online` через File → Open Folder.

## Запуск на своём компьютере

1. Открыть Terminal → New Terminal.
2. Выполнить `npm.cmd install` (если используешь Windows PowerShell).
3. Выполнить `npm.cmd start`.
4. Открыть **http://localhost:3000**.
5. Создать комнату; скопировать ссылку.

**Важно:** ссылка с `localhost:3000` доступна только на твоём компьютере. Для игры с другом из другого дома нужно развернуть сервер в интернете. Live Server и Netlify Drop недостаточно: нужен Node.js-сервер и WebSocket.

## Как выложить онлайн (Render)

1. Создать GitHub-репозиторий и загрузить **всё содержимое** папки проекта (кроме `node_modules`).
2. На https://dashboard.render.com/ выбрать **New → Web Service**.
3. Подключить GitHub-репозиторий проекта.
4. Язык: Node. Build Command: `npm install`. Start Command: `npm start`. Выбрать тариф **Free**, если он доступен.
5. После успешной публикации открыть выдаваемый Render адрес вида `https://название.onrender.com/`.
6. Создать комнату на этом адресе и отправить другу **ссылку, созданную кнопкой внутри игры**.

Ограничения Render Free: веб-сервис может засыпать после 15 минут отсутствия трафика, стартовать не мгновенно, перезапускаться; комнаты и партии хранятся только в оперативной памяти и пропадут при перезапуске. Для серьёзного проекта добавь базу данных и постоянный сервер.

## Какие файлы редактировать

- `public/index.html` — текст и элементы интерфейса.
- `public/style.css` — цвета, размеры, кнопки, доска, адаптивность.
- `public/app.js` — работа с доской и интерфейсом, обработка кликов.
- `server.js` — комнаты, правила ходов, защита от чужого хода, сообщения.
- `package.json` — зависимости и команды.

## Как работает онлайн

Node.js + Socket.IO пересылает обновления обоим игрокам. Сервер использует chess.js и **проверяет каждый ход**. Первый игрок — белые, второй — чёрные. Третий не подключится. Личная ссылка содержит только код комнаты; токен для переподключения хранится в браузере каждого игрока.

## Ограничения первой версии

- Нет аккаунтов, рейтинга, контроля времени и базы партий.
- Комнаты сбрасываются при перезапуске сервера. После закрытия вкладки можно вернуться по своей ссылке из того же браузера, пока сервер работает.
- Не использовать как защиту ценных личных данных. Это учебный сервис.
- Для запуска из другого дома нельзя просто отправлять другу `localhost`.

## ИИ для создателя комнаты

Создатель комнаты (белые) видит кнопку «🤖 ИИ: выключен» в блоке партии. После включения простой бот делает ходы за него автоматически. У второго игрока кнопки нет; сервер отклоняет попытки включения ИИ с его стороны. ИИ выбирает ходы по простым эвристикам, это **не Stockfish**.

В дружеских матчах заранее договоритесь об игре с ботом.

## Обновление: Stockfish, часы, звуки и настройки

- **Stockfish 19 Lite (однопоточная сборка)**: вместо прежнего простого бота. Только создатель комнаты (белые) видит кнопку «🤖 Stockfish» и может включать/выключать его. Уровень выбирается в **⚙ Настройки**: новичок (Skill 2), средний (Skill 8), сильный (Skill 18). Во время работы Stockfish белыми вручную ходить нельзя. Договоритесь с другом перед партией с помощью движка.
- **Время на каждый ход**: при создании комнаты выбери 30 секунд, 1 минуту (по умолчанию) или 2 минуты. Счёт ведёт сервер, после каждого легального хода часы следующего игрока начинаются заново. При отключении любого игрока часы временно останавливаются. Просрочка приводит к автоматическому поражению по времени.
- **Звук**: тихий звук движения фигуры и отдельный звук сдачи, генерируются Web Audio без внешних аудиофайлов. В настройках можно отключить звук и установить громкость. Некоторые браузеры разрешают звук только после первого клика по странице.
- **Панель справа**: кнопки «← Главное меню», «⚙ Настройки»; над доской видно, кто ходит. Кнопка меню освобождает твоё подключение, но не удаляет комнату немедленно: можно вернуться по сохранённому коду.

Для установки всех зависимостей на своём компьютере после обновления проекта:

```powershell
npm.cmd install
npm.cmd start
```

Если включил Stockfish, а он не запустился, проверь вывод сервера и установку пакета `stockfish` (команда `npm.cmd install`). На маленьких бесплатных серверах запуск движка может быть медленным; одновременно используется **один** движок на несколько комнат.

## Съеденные фигуры и звук взятия

Во время партии по бокам шахматной доски отображаются потерянные фигуры: **слева белые**, **справа чёрные**. Список автоматически формируется по легальным ходам на сервере (включая взятие на проходе), синхронизируется у обоих игроков и очищается после реванша. Цифра внизу показывает количество взятых фигур соответствующего цвета.

При обычном ходе звучит тихий шорох. При взятии фигуры вместо него играет короткий деревянный стук (чуть более низкий, если взяли твою фигуру). Настройки громкости и выключатель звуков продолжают действовать. В разделе «⚙ Настройки» появились отдельные кнопки проверки звуков хода и взятия. Звуки воспроизводятся после первого взаимодействия с сайтом, как разрешает браузер.

## Размещение съеденных фигур (обновление)

Теперь съеденные фигуры показываются **возле того, кто их взял**: сразу под именем верхнего игрока и сразу над именем нижнего игрока. При игре за белых сверху возле чёрных отображаются съеденные ими белые фигуры; снизу возле белых — взятые ими чёрные фигуры. Когда игрок заходит за чёрных, расположение автоматически меняется в соответствии с развёрнутой для него доской. При реванше списки обнуляются.
