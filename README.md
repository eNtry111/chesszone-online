# ChessZone Online — сборка для хостинга без шахматного бота

Это отдельная версия ChessZone на Node.js, Express, Socket.IO и chess.js.

## Возможности

- Онлайн-шахматы двух игроков: шестисимвольные комнаты, ссылки, приглашения по никнейму.
- Смена цвета после реванша, таймер, чат, история ходов и съеденные фигуры.
- Звуки и разные цветовые темы.
- «Свобода хода»: фигуры сохраняют правила передвижения, но шах и мат можно игнорировать.
- Дополнительное правило ChessZone: когда у одной стороны остаётся только король, а у другой — король и хотя бы одна другая фигура, побеждает сторона с фигурами. Если остались два короля — ничья. Работает и в режиме свободы.

## Развёртывание

Нужен серверный хостинг для Node.js с поддержкой WebSocket, например Render Web Service. Build Command: `npm install`; Start Command: `npm start`. Можно использовать готовый `render.yaml`.

Локально: `npm.cmd install`, `npm.cmd start`; открой http://localhost:3000.

Ники временные, без регистрации. Комнаты хранятся в памяти сервера и сбрасываются при перезапуске.
