# ChessZone Online

Шахматы с другом по ссылке/нику и отдельная игра против **Stockfish 19 Lite**. Сервер проверяет ходы, хранит позиции и ведёт часы.

**Эта версия: без ИИ-помощника в партии с другом.** Stockfish играет только как отдельный соперник. Старое событие помощника отклоняется сервером.

## Запуск

Установи Node.js 20 или новее, распакуй архив и открой всю папку проекта в VS Code. В терминале Windows:

```powershell
npm.cmd install
npm.cmd start
```

В macOS/Linux: `npm install` и `npm start`. Открой **http://localhost:3000**. Stockfish устанавливается вместе с зависимостями; папка `node_modules` в архив не включена.

## Против Stockfish

1. Введи ник в главном меню.
2. Выбери время на ход: 30 секунд, 1 или 2 минуты.
3. В блоке «Сыграть против Stockfish» выбери **Новичок / Средний / Сильный** и нажми «Играть против ИИ».
4. В первой партии ты играешь белыми. ИИ ходит за соперника.
5. Сложность можно менять в настройках: Skill Level 2, 8 и 18. Это параметры движка, не рейтинги Elo.
6. После завершения нажми «Сыграть ещё раз». Цвета поменяются; если бот стал белыми, он начинает сам.

Позиция и сложность восстанавливаются при обновлении страницы, пока работает сервер и сохранён токен браузера. Другой человек не может занять место бота. «Свобода хода» недоступна против Stockfish: движок требует обычную позицию.

При сбое движка появляется сообщение и кнопка «Повторить ход ИИ»; часы стоят на паузе. Подожди несколько секунд и повтори попытку. Один процесс Stockfish обслуживает ограниченную общую очередь; при высокой нагрузке ответы могут задерживаться.

## С другом

- Оба человека открывают один работающий сервер и выбирают уникальные ники из 2–24 букв, цифр, `_` или `-`.
- Нажми «Сохранить ник», чтобы получать приглашения. Ники временные, без паролей и аккаунтов; после отключения ник может занять другой посетитель.
- Создай комнату и отправь ссылку или шестизначный код. Либо пригласи друга по нику: комната создастся автоматически.
- Приглашение действует 45 секунд. Его можно принять или отклонить; занятый игрок не получает новое приглашение.
- Токен возвращения хранится в localStorage, в ссылке его нет. Занятый ник больше не блокирует восстановление своего места по токену.
- При открытии партии во второй вкладке место переносится туда, первая возвращается в меню.
- При отключении игрока часы останавливаются. После возвращения отсчёт продолжается с оставшегося времени.
- Сдача завершает партию. Реванш требует согласия обоих и меняет цвета.

## «Свобода хода»

Создатель партии с другом включает режим в настройках. Сохраняются геометрия ходов, блокировка фигурами, очерёдность, рокировка, взятие на проходе и превращение. Можно игнорировать шах, ходить под удар, рокировать через шах и брать короля. После взятия короля игра продолжается, пока у очередной стороны есть ходы. Часы остановлены.

Режим можно включить после мата, сдачи или поражения по времени. Правило одинокого короля продолжает действовать. При выключении режима доска сбрасывается в начальную позицию, цвета сохраняются.

## Победа при одном короле

- Король против короля и хотя бы одной другой фигуры: сторона с фигурами выигрывает сразу.
- Два короля без других фигур: ничья.
- Если в свободном режиме один король съеден, это правило не применяется.

Это пользовательское правило, отличающееся от официальных шахмат. Оно действует в обоих архивах: с другом, против ИИ и в свободном режиме.

## Оформление и звук

Есть 12 тем, свои цвета доски, фона и кнопок, случайная палитра и сброс. Звуки движения, взятия и сдачи можно отключить или изменить громкость. Браузер разрешает звук после первого действия на странице. Настройки сохраняются локально; друг видит свою тему. Взятые фигуры расположены возле того, кто их взял.

## Размещение в интернете

Нужен Node.js-сервер с WebSocket, например Web Service с командами сборки `npm install` и запуска `npm start`. Для Render есть `render.yaml`. Порт задаётся переменной `PORT`, локально — 3000.

`localhost` работает только на твоём компьютере. Для друга нужен публичный адрес сервера. Netlify Drop и VS Code Live Server не запускают Node.js-часть.

**Ограничения:** комнаты, позиции и приглашения находятся в памяти одного процесса и исчезают после перезапуска. Нет постоянных аккаунтов, базы партий и рейтинга. Комнаты без подключённых игроков удаляются после суток неактивности. Это учебный проект.

## Файлы и проверки

- `server.js` — комнаты, приглашения, проверка ходов, часы и компьютерный соперник.
- `stockfish-engine.js` — очередь запросов и процесс Stockfish.
- `public/app.js`, `public/index.html`, `public/style.css` — интерфейс.
- `test/server.test.js` — тесты на настоящих Socket.IO-соединениях. Ответы ИИ управляются тестом для проверки гонок.
- `test/stockfish-smoke.js` — запуск настоящего Stockfish на трёх сложностях.
- `CODE_REVIEW.md` — найденные ошибки, исходные строки и исправления.

